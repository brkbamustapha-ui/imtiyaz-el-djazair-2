# Static assets

> The school's logo is **not** here. Drop it into `storage/media/brand/`
> (see the README there) or upload it from Admin → Site settings.

| Path | What it is |
| --- | --- |
| `partners/` | Placeholder tiles for partner logos. Replace them from Admin → Partners with the official artwork you are licensed to display. |
| `gallery/` | Abstract graphics used by the demo gallery. Replace with real photographs. |
| `social-card.png` | Fallback image for social-media shares. It is typography on the brand gradient and contains **no logo**; upload the school's own share image from Admin → Site settings to replace it. |
